# グリーン診断ラボ（green-shindan-labo）

観葉植物を「置きたい場所と、かけられる手間」から選ぶための小さな診断サイトです。
4つの質問に答えると、5種の観葉植物から相性のいいものを1〜2種おすすめします。

- 診断ツール（トップページ）: 日当たり / お世話の手間 / 重視したいこと / ペットの有無
- 植物図鑑: パキラ・モンステラ・サンスベリア・ポトス・ガジュマル
  （特徴・置き場所・水やり・鉢と土・虫がつきにくくするコツ・飾り方・向いている人）

**診断の回答はサーバーに送信しません。** 計算はすべてブラウザの中で行い、
最後の回答だけを利用者の端末（localStorage）に保存します。

## 技術構成

| 項目 | 内容 |
|---|---|
| フレームワーク | Astro（静的出力） |
| ホスティング | Cloudflare Workers（静的アセット配信） |
| テスト | node:test（`src/lib/*.test.ts`） |
| 型チェック | `astro check` |

```
npm install
npm test         # 診断ロジック・データ検証のテスト
npm run check    # 型チェック + テスト
npm run build    # dist/ に静的出力
npm run preview  # ビルド結果を確認
```

開発・運用のルールは [AGENTS.md](./AGENTS.md) を参照してください。
